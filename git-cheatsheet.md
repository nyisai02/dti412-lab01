
# 🐙 Git Command Cheat Sheet

| Command | Purpose |
| :--- | :--- |
| `git --version` | Check the installed Git version. |
| `git config --global user.name "Your Name"` | Set your Git username. |
| `git config --global user.email "your@email.com"` | Set your Git email address. |
| `git config --list` | Show Git configuration information. |
| `git clone <repository-url>` | Download a GitHub repository. |
| `git status` | Display file status (modified, staged, untracked). |
| `git add .` | Add all modified files to staging area. |
| `git commit -m "message"` | Save changes locally with a descriptive message. |
| `git push` | Upload local commits to GitHub/remote. |
| `git pull` | Download and integrate changes from GitHub/remote. |
| `git log --oneline` | Display project history in a compact format. |
| `git branch <branch-name>` | Create a new branch. |
| `git checkout <branch-name>` | Switch to another branch. |
| `git merge <branch-name>` | Merge another branch into the current branch. |
